# Як підключити SimpleVNC до Claude

Після підключення Claude зможе сам дивитися на екран вашого Windows-ПК, клацати мишею
і друкувати — наприклад: «відкрий налаштування Wi-Fi і скажи, до якої мережі я підключений».

Працює це через маленьку програму-міст `simplevnc-mcp`. Вона запускається на тому комп'ютері,
де працює Claude (Mac, Windows чи Linux), і підключається до ПК як звичайний VNC-клієнт.

## Що потрібно

| Що | Де взяти |
|---|---|
| Адреса й порт ПК | Сторінка підключення SimpleVNC або вікно встановлення служби, наприклад `192.168.1.20:5912`. З іншої мережі — адреса Tailscale. |
| Пароль | Найкраще окремий пароль для агентів (див. «Безпека» нижче). Підійде й основний. |
| Файл моста | Тека `dist/`: `simplevnc-mcp-darwin-arm64` для Mac на Apple Silicon, `-darwin-amd64` для Mac на Intel, `-windows-amd64.exe` для Windows, `-linux-amd64` для Linux. |

## Крок 1. Покладіть міст на комп'ютер із Claude

Скопіюйте потрібний файл у постійне місце, наприклад у домашню теку.

На Mac зробіть його запускним і зніміть блокування завантажених програм:

```
chmod +x ~/simplevnc-mcp-darwin-arm64
xattr -d com.apple.quarantine ~/simplevnc-mcp-darwin-arm64
```

Друга команда може відповісти «No such xattr» — це нормально, блокування просто не було.

## Крок 2. Підключіть міст до Claude

Оберіть свій варіант. В усіх прикладах замініть адресу, пароль і шлях до файла на свої.

### Claude Code — термінал і вкладка Code у застосунку Claude

Mac або Linux:

```
claude mcp add --scope user \
  --env SIMPLEVNC_HOST=192.168.1.20:5912 \
  --env SIMPLEVNC_PASSWORD=ваш_пароль \
  --transport stdio windows-pc -- ~/simplevnc-mcp-darwin-arm64
```

Windows (PowerShell), якщо Claude працює на тому самому ПК:

```
claude mcp add --scope user --env SIMPLEVNC_HOST=127.0.0.1:5912 --env SIMPLEVNC_PASSWORD=ваш_пароль --transport stdio windows-pc -- "C:\шлях\до\simplevnc-mcp-windows-amd64.exe"
```

- `--scope user` робить підключення доступним у всіх ваших проєктах. Без нього воно діє лише
  в поточній теці.
- `windows-pc` — назва підключення, можна будь-яку.
- Перевірити: `claude mcp list`. Прибрати: `claude mcp remove windows-pc`.
- У відкритому сеансі команда `/mcp` показує стан підключення.

### Claude Desktop — звичайний чат

1. Меню **Claude → Settings… → Developer → Edit Config**. Відкриється файл
   `claude_desktop_config.json`
   (на Mac він лежить у `~/Library/Application Support/Claude/`, на Windows — у `%APPDATA%\Claude\`).
2. Додайте блок `mcpServers`. Шлях має бути повним, без `~`:

```json
{
  "mcpServers": {
    "windows-pc": {
      "command": "/Users/ваше_ім'я/simplevnc-mcp-darwin-arm64",
      "env": {
        "SIMPLEVNC_HOST": "192.168.1.20:5912",
        "SIMPLEVNC_PASSWORD": "ваш_пароль"
      }
    }
  }
}
```

3. Повністю закрийте Claude і запустіть знову.
4. У полі введення натисніть значок «+» → **Connectors** → **Manage connectors** — там має
   з'явитися `windows-pc` з інструментами.

Якщо у файлі вже є інші сервери, додайте `windows-pc` поруч із ними всередині `mcpServers`.

### Cursor

Файл `~/.cursor/mcp.json` — той самий блок `mcpServers`, що й для Claude Desktop.

## Крок 3. Перевірте

Напишіть Claude:

> Зроби знімок екрана мого Windows-ПК і опиши, що на ньому.

Claude попросить дозволу скористатися інструментом `screenshot` і покаже, що бачить.
Потім можна просити дії: «відкрий Блокнот і надрукуй привіт».

Перед кожною дією Claude питає дозволу — так ви бачите, що саме він збирається зробити.

## Безпека

- **Окремий пароль для агентів.** Запустіть сервер із `-agentpass`
  (для служби: `SimpleVNC.exe -install -p основний -agentpass для_агентів`) і дайте мосту саме його.
  Такий сеанс не може нічого натискати у вікнах дозволу Windows та на екрані входу — на них
  відповідаєте ви. З основним паролем агент має ті самі права, що й ви.
- **Лише перегляд.** Додайте `-agentview` на сервері або запустіть міст із параметром `-view-only`
  (у конфігурації — `"args": ["-view-only"]`). Агент бачитиме екран, але нічого не зможе зробити.
- **Пароль у конфігурації** лежить відкритим текстом. Це ще одна причина дати агентові окремий
  пароль, а не основний.
- Агент бачить усе, що на екрані. Закрийте зайве перед тим, як давати йому завдання.

## Якщо не працює

| Що бачите | Що зробити |
|---|---|
| Сервера немає в списку | Перевірте шлях до файла: він має бути повним. Перезапустіть Claude. |
| «cannot reach the VNC server» | ПК вимкнений, служба зупинена або невірна адреса чи порт. З іншої мережі має бути ввімкнений Tailscale на обох пристроях. |
| «сервер не прийняв пароль» у журналі | Невірний пароль. Після кількох спроб сервер на хвилину блокує адресу. |
| Mac не запускає файл | Виконайте `chmod` і `xattr` з кроку 1. |
| Агент клацає повз | Попросіть його спершу зробити новий знімок: координати беруться з останнього. |
| Вікно дозволу Windows «не натискається» | Так і задумано для пароля агентів — підтвердіть його самі. |

Журнал моста Claude Desktop пише у `~/Library/Logs/Claude/mcp-server-windows-pc.log`
(на Windows — `%APPDATA%\Claude\logs\`). Журнал сервера — у вікні SimpleVNC
або в `C:\ProgramData\SimpleVNC\simplevnc.log` для служби.
