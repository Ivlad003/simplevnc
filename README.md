# SimpleVNC

Мінімальний VNC-сервер для Windows: один файл, без встановлення й налаштувань.
Запустив — і підключайся з Mac, iPhone, iPad, Linux чи іншого Windows.

## Швидкий старт

1. Запустіть `SimpleVNC.exe`.
2. У браузері відкриється сторінка з адресами, паролем і QR-кодами.
3. Підключіться зручним способом:
   - **iPad, телефон:** наведіть камеру на QR-код «У браузері» — екран відкриється
     просто в браузері, без застосунку.
   - **Mac:** ПК сам з'являється у Finder → «Мережа». Або Finder → `Cmd+K` → `vnc://адреса:порт`.
   - **Windows, Linux:** TigerVNC, UltraVNC, Remmina — адреса `адреса:порт`.

Пароль випадковий на кожен запуск. Сервер зупиняється, коли закрити його вікно.

## Служба Windows

Звичайна програма не бачить вікон дозволу Windows (UAC) та екрана входу: поки таке
вікно відкрите, картинка завмирає, а кліки не проходять. Так само не клікаються
програми, запущені від імені адміністратора. Служба цих обмежень не має і стартує
разом із Windows.

```
SimpleVNC.exe -install -p мійпароль
```

Windows попросить підтвердження (потрібні права адміністратора). Програма копіюється
в `Program Files\SimpleVNC`, додається правило брандмауера «SimpleVNC». Якщо пароль
не вказати, він згенерується й буде показаний один раз. Журнал служби —
`C:\ProgramData\SimpleVNC\simplevnc.log`.

Видалити службу: `SimpleVNC.exe -uninstall`.

## ШІ-агенти (MCP)

Агент (Claude Code, Cursor) може керувати цим ПК з будь-якого комп'ютера. Для цього є
окрема маленька програма `simplevnc-mcp`: для агента вона — сервер MCP з інструментами,
а до ПК підключається як звичайний VNC-клієнт. Збірки для Mac, Windows і Linux — у `dist/`.

| Інструмент | Що робить |
|---|---|
| `screenshot` | Знімок екрана, зменшений під модель. |
| `zoom` | Ділянка екрана в повній роздільності — щоб прочитати дрібний текст. |
| `click`, `move_mouse`, `drag`, `scroll` | Миша. |
| `type_text` | Друкує текст буквально, будь-якою мовою. |
| `press_keys` | Клавіша або комбінація: `Enter`, `ctrl+c`, `alt+F4`. |

Підключення в Claude Code на Mac:

```
claude mcp add --env SIMPLEVNC_HOST=адреса:порт --env SIMPLEVNC_PASSWORD=пароль \
  --transport stdio windows-pc -- /шлях/до/simplevnc-mcp-darwin-arm64
```

Для Cursor — той самий запуск у `~/.cursor/mcp.json` (`command` і `env`).

**Окремий пароль для агентів.** Запустіть сервер із `-agentpass інший_пароль` (для служби:
`-install -p основний -agentpass для_агентів`). Сеанс із цим паролем не може нічого натискати у
вікнах дозволу Windows та на екрані входу — на такі запити відповідає людина. З `-agentview`
агент лише дивиться. З основним паролем агент має ті самі права, що й ви.

Щоб агент лише спостерігав незалежно від сервера, запускайте міст із `-view-only`.

## Параметри

Усі необов'язкові.

| Параметр | Що робить |
|---|---|
| `-p пароль` | Постійний пароль (до 8 символів — обмеження протоколу VNC). |
| `-nopass` | Без пароля. Лише для довіреної мережі. |
| `-port N` | Порт. Типово 5900; якщо він зайнятий, береться наступний вільний. |
| `-bind адреса` | Слухати лише на одній адресі. Типово — на всіх. |
| `-scale N` | Розмір кадру у відсотках: 100, 75, 66, 50, 33 або 25. Змінюється також на сторінці. |
| `-area X` | Що транслювати: `all`, `left`, `right`, `m1`, `m2`… або `x,y,ширина,висота`. |
| `-drawcursor` | Завжди малювати курсор у кадрі: видно рухи миші того, хто сидить за ПК. |
| `-noopen` | Не відкривати сторінку підключення в браузері. |
| `-nobonjour` | Не оголошувати ПК у локальній мережі. |
| `-install`, `-uninstall` | Встановити або видалити службу Windows. |
| `-agentpass пароль` | Окремий пароль для ШІ-агентів, без доступу до вікон дозволу Windows. |
| `-agentview` | Агенти з паролем `-agentpass` лише дивляться. |
| `-gdi` | Захоплювати екран лише через GDI. |
| `-v` | Показувати статистику захоплення. |

## Як це працює

- **Захоплення:** DXGI Desktop Duplication — кадр береться з відеокарти й лише тоді, коли екран
  змінився. Якщо DXGI недоступний, сервер сам переходить на GDI.
- **Передача:** екран ділиться на клітинки 32×32, клієнту йдуть лише змінені. Кодування ZRLE,
  Zlib або Raw. Картинка без втрат якості.
- **Курсор:** клієнт малює його сам у місці свого вказівника, тож миша не «відстає».
  Якщо хоч один клієнт цього не вміє, курсор домальовується в кадр.
- **Область і роздільність:** можна транслювати один монітор чи половину екрана й зменшити кадр.
- **Веб-клієнт:** вбудований [noVNC](https://novnc.com) працює поверх WebSocket на порту 6080+.
- **Ввід:** миша, клавіатура (включно з кирилицею й комбінаціями на кшталт `Ctrl+C`).
- **Буфер обміну:** UTF-8 для клієнтів із розширеним буфером (TigerVNC, noVNC), Latin-1 для решти.
- **Сторінка підключення:** доступна лише з цього комп'ютера (`127.0.0.1`), тож пароль
  не потрапляє в мережу.
- **Служба:** сама служба працює в сеансі 0 і лише запускає робочий процес із правами SYSTEM
  у сеансі користувача; той стежить за активним робочим столом і переходить на захищений.

| Файл | Зміст |
|---|---|
| `main.go` | Параметри, запуск, прийом з'єднань. |
| `rfb.go` | Протокол RFB: рукостискання, пароль, повідомлення клієнта, відправка кадрів. |
| `capture.go` | Цикл захоплення, пошук змін, масштабування, GDI. |
| `dxgi.go` | Захоплення через DXGI. |

| `area.go` | Монітори й область трансляції. |
| `input.go`, `desktop.go` | Миша й клавіатура; потік вводу й перехід між робочими столами. |
| `clip.go` | Буфер обміну. |
| `web.go`, `page.html` | Сторінка підключення з QR-кодами. |
| `webclient.go`, `novnc/` | Веб-клієнт і міст WebSocket. |
| `bonjour.go` | Оголошення ПК у локальній мережі. |

## Збірка

Потрібен Go 1.21 або новіший, лише Windows.

```
go build -trimpath -ldflags "-s -w" -o SimpleVNC.exe .
```

Міст для агентів, наприклад під Mac з процесором Apple:

```
GOOS=darwin GOARCH=arm64 go build -trimpath -ldflags "-s -w" -o dist/simplevnc-mcp-darwin-arm64 ./cmd/simplevnc-mcp
```

## Обмеження

- Трафік VNC не шифрується, веб-клієнт працює по HTTP. Через інтернет користуйтеся VPN
  (наприклад, Tailscale) або SSH-тунелем.
- У режимі служби пароль дає повний доступ до ПК, включно з вікнами дозволу Windows.
  Правило брандмауера діє для всіх типів мереж; звузити його можна в налаштуваннях Windows.
- `Ctrl+Alt+Del` надіслати не можна. Розблокувати ПК це не заважає: досить клацнути по екрану.
- Курсор малює клієнт, тому рухів миші того, хто сидить за ПК, віддалено не видно
  (вмикається параметром `-drawcursor`).
- Windows може зарезервувати порт 5900 під Hyper-V чи WSL. Тоді сервер бере інший порт,
  і його треба вказувати в адресі.
- Стиснення з втратами (JPEG) немає: на дуже повільній мережі допоможе менша роздільність.
